  # Калькулятор выгоды (Kaspi vs BCC)
  
  Минималистичный веб-калькулятор для точного сравнения финансовых продуктов: рассрочка Kaspi, Kaspi Gold, BCC KartaKarta и BCC ironCard. Помогает принять математически обоснованное решение при крупных покупках.
</div>

## 🎯 Главные фишки
- **Точная математика**: Эмулятор депозита Kaspi "Моя Цель" с капитализацией строго 1-го числа каждого месяца.
- **Поддержка Apple Shortcuts**: Умеет автоматически парсить цены товаров через URL-параметры `?price=X`.
- **Генерация PDF**: Встроенная выгрузка детализированного графика платежей в PDF.
- **Kaspi Design System**: Минималистичный и чистый UI, кастомный выбор даты (squircle-кнопки, iOS-стиль).
- **Сравнение 4 способов оплаты** одновременно.

## 🛠 Стек технологий
- **HTML5 & CSS3**: Native-look UI, адаптивная верстка, glassmorphism.
- **Vanilla JavaScript**: Никаких фреймворков (No React/Vue), максимальная производительность.
- **pdfmake**: Векторная генерация PDF на клиенте.
- **Pillow / Python**: Скрипты генерации и обрезки графики.

## 🚀 Использование
Приложение работает полностью в браузере (Client-side). Вы можете развернуть его на любом статическом хостинге (GitHub Pages, Vercel, Netlify).

1. Введите стоимость товара.
2. Выберите срок рассрочки и дополнительные параметры (кешбэк/лимиты).
3. Приложение автоматически подсветит самый выгодный математический вариант.
